Livraison

Après le paiement, ton code s'affiche sur la page klozio.app/code. Il figure aussi dans le reçu que Stripe t'envoie par e-mail. Saisis-le dans le jeu (« J'ai un code ») : l'offre s'ouvre sur l'appareil.

Un code fonctionne sur 3 appareils au plus. Au-delà, il est refusé sur un nouvel appareil. Pour en libérer un, écris-nous avec ton code.

Si un problème technique t'empêche d'utiliser ton code, écris-nous. S'il n'est pas résolu dans les 7 jours qui suivent ton message, tu es remboursé en totalité, sur la carte utilisée.
